# NumHunter

OSINT-инструмент для анализа номеров телефонов.

## Возможности

- Проверка одного номера
- Batch-обработка списка из файла
- Валидация номеров
- Экспорт отчётов в JSON
- Встроенная статистика

## Установка

pip install phonenumbers

## Запуск

python3 numhunter.py

## Что показывает

- Страну и регион
- Оператора связи
- Тип линии (мобильный, городской, VoIP)
- Часовой пояс
- Ссылки для проверки в соцсетях

## Важно

Работает только с открытыми данными. Не собирает персональную информацию и не отслеживает местоположение.
