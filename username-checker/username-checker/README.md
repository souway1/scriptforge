# Username Checker 🔍

Асинхронный OSINT-инструмент для проверки юзернеймов по 100+ платформам.

## Что делает

Скрипт принимает никнейм и проверяет его существование на 100+ популярных сайтах: соцсети, форумы, платформы для разработчиков, дизайнеров, музыкантов и геймеров. Результат сохраняется в JSON-файл.

## Возможности

- ✅ Асинхронная проверка (все сайты проверяются одновременно)
- ✅ 100+ платформ (GitHub, Reddit, Steam, TikTok, Spotify и др.)
- ✅ Цветной вывод в консоль
- ✅ Сохранение отчёта в JSON
- ✅ Обработка таймаутов, блокировок и ошибок
- ✅ Retry-логика (2 попытки при ошибке)

## Установка

```bash
pip install aiohttp
```

Запуск

```bash
python3 checker.py
```

Введи ник, когда скрипт попросит:

```
Введи ник: durov
```

Пример вывода

```
[+] GitHub         — https://github.com/durov
[+] Reddit         — https://www.reddit.com/user/durov
[-] Steam          — не найден
[!] TikTok         — заблокирован
...
Найдено: 27
Не найдено: 8
Заблокировано: 16
Ошибок: 40
```

Формат отчёта (JSON)

```json
{
  "username": "durov",
  "timestamp": "2026-09-25T06:40:00",
  "found": [{"site": "GitHub", "url": "https://github.com/durov"}],
  "not_found": ["Steam", "Blogger"],
  "blocked": ["TikTok", "Airbnb"],
  "errors": ["Binance", "CoinMarketCap"]
}
```

⚠️ Важное предупреждение

Некоторые платформы (TikTok, Instagram) возвращают статус 200 даже для несуществующих пользователей, показывая страницу-заглушку «Пользователь не найден». Это может дать ложное срабатывание [+]. Это не ошибка скрипта — это особенность защиты платформ.

Часть сайтов (Binance, CoinMarketCap, Airbnb) не отвечают без авторизации. Они помечаются как [!] ошибка.
